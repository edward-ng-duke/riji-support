Privacy / 隐私政策

你的日子，由你保管。

本政策说明日拾正式版如何处理记录，以及你选择连接第三方服务时会发生什么。

1. 本机与手表记录

日拾是个人记录工具。录音、转写、重点与摘要、记忆和对话保存在你的设备上。iPhone 可以独立录音，Apple Watch 是可选的采集设备。手表录音通过配对连接交付到 iPhone，由手机完成转写与档案管理。

日拾正式版不提供开发者运营的录音或文字存储服务器。开发者无法通过日拾远程读取你的档案。录音与转写在设备上处理，本机搜索使用设备端能力。正式版不读取 Apple 健康数据。

请在合法、知情的前提下录音，并尊重被录音者的权利。应用在录音期间保持可见状态提示，使用系统的麦克风权限与录音指示。

2. 可选 AI 服务

你可以先使用录音、转写、回看与搜索，再决定是否连接 AI。选择自定义 AI 时，需要提供你自己的 API Key，并先阅读与同意发送说明。同意页会显示服务商名称、接口主机以及将发送的内容。更换服务商或接口主机时，需要对新的接收方同意。

连接后，小时分析、每日回顾和问答会按需发送转写文字、重点与摘要、你确认保存的记忆、提问及相关对话历史。开启地点数据时，还可能包含市与区县。原始音频、健康数值、坐标和街道不发送给 AI。

这些文字由 iPhone 直接发往你选择的服务商。服务商可通过 API 凭据将请求与你在该服务的账户关联，也可能根据其政策保留请求内容、安全日志及用量信息，或在其条款允许的范围内处理数据。连接前请查阅该服务的隐私政策、适用地区和账户设置。日拾无法替服务商承诺统一的保留期限。

你可以关闭「自动生成重点与摘要」和「每日回顾」，或删除该服务商的 API Key 以停止后续发送。已发送内容的删除与保留应向接收服务商申请。

在受支持机型上，你也可以下载本机模型。模型推理在该 iPhone 上完成，不发送推理内容到模型下载源。模型下载本身需要联网。

3. 地点

地点功能可选。只有你允许位置权限、开启地点功能、日拾处于前台且正在录音时，应用才记录粗略位置。只用手表录音、手机处于后台时不会记录地点。

本机保存约 1 公里精度的取整坐标。默认使用离线地名数据转换为市与区县。开启「显示地点名称」后，应用会将同样取整的粗略位置发给 Apple 进行地名反查。Apple 的处理适用其隐私政策。

开启地点功能后，AI 请求只会带上解析得到的市与区县，不带坐标和街道。关闭地点会停止今后的采集及新 AI 请求对地点的使用，已有记录可由你另行删除。

4. 凭据与权限

API Key 按服务商保存在仅限本设备的系统钥匙串中，不进入普通导出、加密恢复包或调试信息。该凭据会用于你所选接口的身份验证。请妥善管理其权限、额度与有效期。

录音需要麦克风权限。地点使用系统位置权限。根据设备和语音识别路径，Apple 可能要求语音识别授权及资源下载。系统通知用于提示录音中断等状态。你可以在系统设置中管理这些权限，拒绝某项权限会影响对应功能。

5. 删除、导出与恢复

档案默认排除在 iCloud 与系统设备备份之外。请自行保存所需的导出和恢复包。原始音频按你设置的保留期限清理，转写与派生文字保留到你主动删除。你可以删除原始音频、某段记录、某个小时或某一天，以及关联的派生内容。

普通转写导出为 Markdown 和 JSON。这些文件可能含有你的私人内容，保管与分享由你决定。完整恢复包使用你设置的密码加密，包含转写、记忆、AI 结果与来源关系，不包含 API Key 和模型文件。日拾不保存恢复包密码，忘记密码后无法由开发者找回。

恢复时，恢复包合并到本机档案，重复内容保留一份，本机已有删除标记的内容不会被恢复回来。恢复到其他设备后，需要重新填写 API Key、重新取得相应服务商的发送同意，并按需下载模型、与手表重新握手。

你通过系统「文件」或分享功能保存到其他设备或云服务的副本，按所选保存位置的规则处理。本机删除不会自动删除你保存的导出副本，也无法撤回第三方 AI 已收到的内容。

6. 资源下载与其他联网

「检查连接」会向你选的 AI 接口发送固定测试文字，不含你的记录。通过连接后，自动分析与每日回顾可在你允许的设置下请求该服务。

本机模型仅通过 Wi-Fi 从你选择的 ModelScope、hf-mirror.com 或 Hugging Face 下载，下载完成后校验文件。下载源及其内容分发网络可以看到网络请求必需的信息，例如 IP 地址、请求时间、请求文件和客户端信息，并可能依其政策保留访问或安全日志。模型下载不会上传录音、转写或记忆。

系统可能按需从 Apple 下载语音识别、语义资源或字体。可选的地名反查也通过 Apple 服务完成。网络传输及相关服务由各网络与服务提供者依其政策处理。

日拾未集成广告、跨应用追踪、第三方统计或崩溃上报 SDK。系统自身的诊断与分析设置由你在 Apple 系统中管理。

7. 支持联系与本网站

你主动发送支持邮件时，开发者会收到你的邮箱地址、邮件正文和你选择添加的附件，用于答复与排查。请优先提供设备型号、系统版本、应用版本、发生时间和复现步骤，并在发送截图或调试包前检查其中的私人信息。

本支持站使用 GitHub Pages 托管，不加载分析脚本、广告或远程字体。网站托管方可依其政策处理访问连接与日志信息。通过网页发送邮件会打开你自己的邮件客户端。

有关托管服务的数据处理，可阅读 GitHub 隐私声明。有关 Apple 服务，可阅读 Apple 隐私政策。
