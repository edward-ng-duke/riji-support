日拾使用支持隐私政策服务条款

Terms / 服务条款

认真记录，审慎使用。

这些条款适用于日拾正式版的个人记录功能。

生效日期 2026 年 11 月 4 日

1. 使用范围

日拾用于个人录音、转写、回看、搜索与可选 AI 整理。请在有权录音、保存和处理相关内容的前提下使用，并遵守所在地法律及被录音者的知情与同意要求。

2. 功能与结果

转写、重点、摘要、回顾、记忆候选与问答可能存在遗漏或错误。重要事实请回到转写原文与保留的原音核对。日拾不提供医疗诊断，也不会执行录音中出现的指令。

录音与同步受设备状态、权限、存储和系统调度影响。日拾不承诺连续 24 小时不中断录音，也不承诺固定时间完成同步或回顾。

3. 自定义 AI 与本机模型

日拾正式版本身免费，没有应用内购买或订阅。使用自定义 API 时，由你选择服务商、提供 API Key，并阅读与同意发送说明。相关 API 费用由你直接向服务商支付，接收方的数据处理按其条款执行。

本机模型只在受支持设备上运行。模型文件通过你选择的第三方来源下载，并适用模型各自许可。较小的本机模型可能更容易遗漏或生成错误结果。

4. 档案与备份

请自行保管设备、API 凭据、导出文件、恢复包及密码。档案默认排除在 iCloud 与系统设备备份之外，开发者没有可用于恢复的档案副本或密码。数据处理、删除与恢复的具体规则见 隐私政策。

5. 开源组件与数据

日拾使用的开源组件、模型与地名数据在「设置 → 开源许可」中列明。离线地名采用 geoBoundaries / OpenStreetMap 与 GeoNames 数据，分别遵守相应的 ODbL 1.0、CC BY 4.0 及其他适用许可。可公开获取的数据、修改与许可见 数据来源与许可 页面。
