常见问题

从这里开始。

没有 Apple Watch 可以使用吗？

可以。iPhone 可以独立录音、转写、回看、搜索与导出。Apple Watch 提供可选的手表采集与标记功能，手表录音交付到配对的 iPhone 后处理。

没有连接 AI 或没有网络，可以做什么？

录音、设备端转写、时间线浏览、保留原音的回放、关键词与语义搜索、导出可独立使用。部分系统资源首次使用时可能需要联网下载。

小时重点、每日回顾和 AI 问答需要你连接自己的 API 服务，或在受支持机型下载本机模型。你可以在首次引导中先不用 AI。

如何连接自己的 AI 服务？

进入「设置 → AI 设置」，选择自定义 API 与服务商，填写你自己的 API Key，阅读发送说明并同意，再检查连接并保存。自定义接口还需要填写完整地址与模型名。

连接后，当次所需文字直接发送给你选择的服务商，其费用、数据保留和账户限制依该服务商规则执行。停止自动调用可关闭自动生成与每日回顾，停止后续发送可删除对应 API Key。

为什么没有本机模型选项，或模型暂时不能运行？

本机模型受设备物理内存限制，目前面向 8GB 及以上机型。下载需要 Wi-Fi 和足够空间，请保持日拾在前台。低电量模式、过热或离开前台时，本机推理会暂停。

模型结果可能遗漏或出错。请回到转写与原音核对重要事实。

录音为什么会中断？

来电、音频被其他应用占用、低电量、可用存储或系统调度都可能影响录音。日拾会标记录音中断与缺口。请检查麦克风权限、存储空间及录音页面提示，再开启新的录音。

应用不承诺连续 24 小时不中断录音。

手表录音为什么还没有出现在手机上？

配对传输由系统安排，后台交付可能延迟。请让 iPhone 与 Apple Watch 保持正常连接，在两端打开日拾，查看手表同步状态，并使用页面上的同步或重试入口。

如需反馈，附两端状态与问题时间。请先保留仍在手表上的录音与排队记录。

换手机或丢失设备后，如何找回档案？

档案默认排除在 iCloud 与系统设备备份之外。请提前在「设置 → 导出与备份」生成并保存加密恢复包，妥善保管密码。

在新设备上选择恢复包进行合并恢复，之后重新填写 API Key、下载所需模型，并与手表重新握手。开发者没有你的档案副本或恢复包密码。

如何删除记录及发给 AI 的内容？

应用内可以删除音频、某段记录、某个小时或某一天及其派生内容，也可删除服务商 API Key。你另行保存的导出文件需在保存位置删除。

本机删除无法撤回第三方 AI 已收到的请求。如需删除服务商保存的数据，请按该服务的隐私政策提出请求。

数据处理的详细说明见 隐私政策。组件与离线地名数据的署名可在应用「设置 → 开源许可」及本网站的 数据来源与许可 页面查看。
